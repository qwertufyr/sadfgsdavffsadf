# Сборка мода в .jar

## Вариант C — в облаке через GitHub Actions (если сборка на своём ПК не идёт)

Если Gradle/IntelliJ на твоём компьютере не может достучаться до сети
(даже с выключенным VPN/фаерволом — бывает и такое, дело в системном
сетевом стеке), проще всего собрать jar не у себя, а на серверах GitHub —
бесплатно и без единой команды в терминале.

1. Зарегистрируйся на https://github.com (если ещё нет аккаунта).
2. Создай новый репозиторий: кнопка **New** → любое имя (например
   `nullreach-prop`) → можно **Private** → **Create repository**.
3. На странице пустого репозитория нажми **uploading an existing file**
   (или "Add file → Upload files") и перетащи **все файлы и папки** из
   `nullreach-fabric-mod` (включая скрытую папку `.github` — если она не
   видна в проводнике, включи показ скрытых файлов, или просто перетащи
   всю папку `nullreach-fabric-mod` целиком, GitHub сам разберёт структуру).
4. Внизу нажми **Commit changes**.
5. Перейди на вкладку **Actions** вверху репозитория — сборка запустится
   автоматически (или нажми **Run workflow**, если нет автозапуска).
6. Подожди 2-4 минуты, пока не появится зелёная галочка.
7. Кликни на завершённый запуск → внизу раздел **Artifacts** → скачай
   **nullreach-prop-jar** (это zip, внутри — готовый `.jar`).

Дальше — как обычно: `.jar` из архива в `.minecraft/mods`, вместе с
Fabric API нужной версии.

## Вариант A — через IntelliJ IDEA (проще всего)

1. Установи [IntelliJ IDEA Community](https://www.jetbrains.com/idea/download/) (бесплатная) и [JDK 21](https://adoptium.net/temurin/releases/?version=21).
2. Открой папку `nullreach-fabric-mod` в IntelliJ как проект — она сама
   распознает Gradle-проект и предложит импортировать. Согласись, подожди
   пока подтянутся зависимости (несколько минут при первом разе).
3. Справа откроется панель **Gradle** → `nullreach-prop` → `Tasks` → `build` →
   двойной клик по задаче **build**.
4. Готовый `.jar` появится в `build/libs/nullreach-prop-1.0.0.jar`
   (не бери файл с суффиксом `-sources`, он не нужен для игры).

## Вариант B — через терминал

1. Установи [JDK 21](https://adoptium.net/temurin/releases/?version=21) и
   [Gradle 8.8+](https://gradle.org/install/) (или новее).
2. В папке проекта выполни:
   ```
   gradle build
   ```
3. Файл появится в `build/libs/nullreach-prop-1.0.0.jar`.

## Установка мода

1. Установи [Fabric Loader](https://fabricmc.net/use/) для Minecraft **1.21.11**.
2. Скачай [Fabric API](https://modrinth.com/mod/fabric-api/version/0.141.4+1.21.11)
   под ту же версию — он обязателен, без него мод не загрузится.
3. Положи оба `.jar`-файла (Fabric API + `nullreach-prop-1.0.0.jar`) в папку
   `.minecraft/mods`.
4. Запусти игру через профиль Fabric 1.21.11.

## Хоткей в игре

- **`G`** — открыть меню NULLREACH (лого + кнопка Connect). Жмёшь
  Connect → пара секунд дёрганой загрузки → сообщение об ошибке
  "CONNECTION FAILED / no link to NULLREACH.exe" и кнопка RETRY. Это
  чисто визуальный экран для кадра, ни к чему не подключается.

Переназначить клавишу можно в игре: **Настройки → Управление → NULLREACH Prop**.

## Если сборка не идёт

Fabric часто выпускает новые билды — версии в `gradle.properties`
зафиксированы на момент выхода 1.21.11 (декабрь 2025). Если Gradle ругается,
что не может найти зависимость:

1. Зайди на https://fabricmc.net/develop
2. Выбери Minecraft **1.21.11** и Loader **Fabric**
3. Скопируй актуальные `yarn_mappings` и `loader_version` в `gradle.properties`
4. Для Fabric API актуальную версию под 1.21.11 смотри на
   https://modrinth.com/mod/fabric-api/versions — раздел под именно эту
   версию майна, поле `fabric_version` в `gradle.properties`.

## Важно

Это чисто клиентский реквизит: лаг — это фризы локального рендера,
кик — это самостоятельный выход клиента с кастомным текстом. Мод не
отправляет никакого нестандартного трафика и не взаимодействует с
сервером сверх обычного поведения клиента.

**На будущее:** 1.21.11 — последняя версия Minecraft, для которой Fabric
ещё выпускает Yarn-маппинги (те самые понятные имена вроде `MinecraftClient`,
`Text.literal`), на них написан этот мод. Начиная со следующих версий Fabric
переходит на маппинги Mojang с другими именами классов/методов — если
захочешь обновить мод под более новую версию Minecraft, код нужно будет
переписывать под новую систему имён, это не просто смена номера версии
в `gradle.properties`.
